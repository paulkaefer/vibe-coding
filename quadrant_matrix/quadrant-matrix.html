Keyboard shortcuts

N / AAdd item (at the pointer, or near the center)
E / Enter / F2Edit selected item
Del / ⌫Delete selected item
←↑↓→Nudge selected item (⇧ for bigger steps)
Tab / ⇧TabSelect next / previous item
EscDeselect, or cancel an edit
⌘Z / ⌘⇧ZUndo / redo (Ctrl on Windows & Linux)
⇧CClear all items (undoable)
S / ⌘SExport JSON
O / ⌘OImport JSON (or drop a file on the page)
PExport PNG
?Show / hide this help

Click any title, axis label or corner label to rename it. Double-click an item to edit it. Everything is autosaved in this browser.
