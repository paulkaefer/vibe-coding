## Overview

This repository includes some example "apps" that were vibe coded, and intended to be used as demonstration for SEIS 606: Vibe Coding and/or for personal use.

The idea is to develop a standard/set of conventions (see [CONVENTIONS.md](./CONVENTIONS.md)) that can be followed by anyone who is [vibe coding](https://en.wikipedia.org/wiki/Vibe_coding).

At this time, I am unsure what license would work, given that the code files were generated using Claude (with minimal manual updates).

## To current (and future?) students

Follow instructions in class for referencing/forking this repository. See [CONVENTIONS.md](./CONVENTIONS.md) for the current state of recommended conventions. Remember, this is a work in process!

## To anyone else

You are welcome to explore and use this repository, so long as you do not use the work as your own. Please cite the original author (or "vibe coder!") where appropriate ([Paul Kaefer](https://software.stthomas.edu/about/faculty-staff/biography/paul-kaefer/index.html)).

You are also welcome to take any of the ideas from [ideas.md](./ideas.md) and run with them. Feel free to acknowledge Paul, but note that these ideas were ultimately generated by Claude, with minimal input from Paul.
